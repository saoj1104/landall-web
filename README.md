# 랜드올 (LAND ALL) - 부동산의 모든 것

> 데이터와 실전 경험으로 증명하는 부동산 밸류업 & 공동투자 솔루션  
> **개발(Development) · 중개(Brokerage) · 임대 및 자산운용(Leasing & PM)**

---

## 📌 프로젝트 소개
광주 지역을 중심으로 실전 부동산 가치 혁신 및 공동투자를 선도해 온 **주식회사 랜드올(LAND ALL)**의 공식 웹사이트입니다.

- **실전 트랙레코드**: 2016년부터 이어진 18건의 공동투자 프로젝트 (개인정보 보호를 위한 100% 실명 익명화 완료)
- **핵심 역량**: 상가 용도변경 인허가, 노후 건물 기획 리모델링, 하락장 선제적 위기관리 & 원금 방어
- **반응형 웹**: 모바일, 태블릿, PC 전 기기 완벽 지원

---

## 🛠️ 기술 스택
- **Frontend**: HTML5, CSS3 (Modern Glassmorphism & Custom Theme), Vanilla JavaScript (ES6+)
- **Icons & Fonts**: FontAwesome 6, Google Fonts (Noto Sans KR, Montserrat)
- **Deployment**: GitHub Pages
